# Human reader packets (2026-09-03)

Two readers, two chapters each, two versions. Give each reader the four files in a random order without
saying which is which. Ask only: "Read until you would put the book down. At which paragraph did you stop,
and why, in one sentence." Record the paragraph number and the sentence for each file.

- baseline-chapter-1.md / baseline-chapter-8.md — composed-23a (iteration-23 pipeline, grounded contract)
- best-chapter-1.md / best-chapter-8.md — ladder-5b (creative contract + material-first + couplet rewrite + apparatus)

The put-down paragraph is the readout; a reader who finishes both is recorded as "finished".
